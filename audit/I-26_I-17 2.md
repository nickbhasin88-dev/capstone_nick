# I-26 and I-17 (rest). Fixed

## I-26: missing or old interest data

**Data.**
- IMF World Economic Outlook, **October 2026** edition (published 2026-10-13), from the IMF SDMX API (dataflow
  `IMF.RES:WEO`), downloaded 2026-10-13, for all 71 dashboard countries.
- Series: `GGXONLB_NGDP` (primary net lending/borrowing), `GGXCNL_NGDP` (net lending/borrowing) and `GGR_NGDP`
  (revenue), all % of GDP.
- Raw file: `datasets/IMF_WEO_Oct2026_GG_balances_2026-10-13.csv` (gitignored).
- Processed file: `macro_data/weo_fiscal/weo_balances.csv`, tagged with source and download date. It sits in a
  subfolder so `add_constant_dollars.py`'s glob of country files doesn't pick it up.
- Code: `fiscal_inputs.py`, called last in `who_inputs.apply()`, so a full rebuild gives the same inputs (checked: both
  paths reproduce `country_inputs.csv` exactly).
- **Why the API and not the WEO file:** the classic WEO file (with "Estimates Start After") returns 403 to scripted
  downloads.

**Formula.** interest_to_revenue = (GGXONLB_NGDP - GGXCNL_NGDP) / GGR_NGDP x 100, labelled "net interest (IMF WEO:
primary minus overall balance)", from the latest actual year.
- **Actual vs projection:** the API carries no "estimates start after" year. A year therefore counts as actual only if
  it is before the country's first GDP estimate year in `macro_data/<ISO3>.csv` (from the WEO file).
- This never uses a projection. Where WEO's fiscal accounts are final for a later year than its GDP, it may use one
  year older than possible.

**Rule.**
- Per country, the more recent of World Bank `gc_xpn_intp_rv_zs` and the IMF value (ties: World Bank).
- If neither exists: the median of the dashboard countries in the same income group, marked "(estimated)". No country
  needs this now; it is tested.
- `fiscal_space` raises an error rather than default to a stress factor of 1.

**Display.** The fiscal panel tooltip and chart source read, e.g., "Interest: 61% of revenue (IMF WEO, 2024)". Methods,
the datasets table and Data Years are updated.

**Sources now:** IMF WEO 54 countries, World Bank 17, estimated 0.
